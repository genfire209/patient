Three mechanisms, not six screens

The interface above is what you touch. This is what actually happens underneath it — where the photo goes, what has to succeed before it's shown, and what a doctor's link can and can't do.

Smaller pieces, still interface only
Cloud backup
Would upload the same already-encrypted files to iCloud — no new encryption to design, just wiring up CloudKit.
Hide mode
A second, separate PIN distinct from Face ID, for a faster lock/unlock that doesn't need biometrics.
Language
Apple's on-device speech framework already covers Hindi and English — mostly a picker and a locale switch away.
